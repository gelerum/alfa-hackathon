# Alfa_hack — подбор новостей под компанию

Программа собирает новости RT и Коммерсанта с заданной даты до текущего момента и сортирует их по тому, насколько они похожи на описание компании. Слабо похожие новости отбрасываются.

Это скелет: каждую часть можно заменить, не трогая остальные.

## Как запустить

```bash
python main.py -d 2026-10-20 -c company.txt -p 0.55
```

Быстрый вариант, примерно за минуту вместо 7:

```bash
python main.py -d 2026-10-20 -c company.txt -i short -m cointegrated/rubert-tiny2 -p 0.7
```

| Параметр | Что значит |
|---|---|
| `-d` | с какой даты собирать новости (время московское) |
| `-c` | txt-файл в UTF-8 с описанием компании |
| `-p` | порог похожести от 0 до 1, ниже него новости отбрасываются (по умолчанию 0, то есть все) |
| `-m` | модель эмбеддингов (по умолчанию `deepvk/USER-bge-m3`) |
| `-i` | что подавать в модель: `full` — текст новости, `short` — заголовок + анонс |

Справка: `python main.py -h`.

## Из чего состоит

- **`news_collector.py`** — `get_news(date)` возвращает DataFrame с новостями (источник, заголовок, дата, ссылка, рубрика, анонс, текст).
  - RT: свежие новости берутся из ленты сайта, старые (больше ~3 дней) — из sitemap.
  - Коммерсант: из sitemap, текст — со страницы статьи.
- **`Tokinizer.py`** — работа с текстом:
  - `tokenise(text)` чистит текст (леммы, без стоп-слов и пунктуации) и режет его на подслова модели;
  - `embed(tokens)` даёт один вектор «смысла» на текст;
  - `embed_many([...])` даёт векторы для списка текстов;
  - `load_model(name)` выбирает модель.
- **`main.py`** — собирает всё вместе: новости → векторы → похожесть на компанию → таблица.

Похожесть считается как косинус между вектором новости и вектором описания компании.

## Что сделано для скорости

- Длинные статьи обрезаются до 512 подслов: так быстрее на 10–20%, а топ новостей не изменился.
- Из spaCy убраны лишние части (`parser`, `ner`), результат очистки тот же.
- Пачечное кодирование проверили: на процессоре оно медленнее, поэтому тексты кодируются по одному. С видеокартой это стоит пересмотреть, место для правки — `embed_many`.
- На всех этапах видны прогресс-бары.

## Сравнение режимов

237 новостей за 22.10.2026, описание условного банка. Время — токенизация + эмбеддинги, без сбора новостей.

| Режим | Время | Совпадение топ-10 с основным режимом | Разброс оценок |
|---|---|---|---|
| USER-bge-m3, `full` (основной) | 6.4 мин | 10/10 | 0.26–0.64 |
| USER-bge-m3, `short` | 2 мин | 6/10 | 0.25–0.66 |
| rubert-tiny2, `full` | 25 с | 3/10 | 0.24–0.74 |
| rubert-tiny2, `short` | 9 с | 3/10 | 0.35–0.84 |

Во всех режимах наверху новости про ипотеку и онлайн-банк. Лёгкая модель чаще поднимает новости про долги и банкротства компаний: для банка они тоже по теме, но порядок заметно отличается от основного режима.

**Порог `-p` у каждого режима свой:** у rubert-tiny2 оценки в целом выше, и с порогом 0.55 останется половина новостей. Порог лучше подбирать так: запустить с `-p 0`, посмотреть на оценки и поднять его.

## Установка

```bash
pip install -r requirements.txt
pip install --no-deps spacy-cleaner
python -m spacy download ru_core_news_sm
```

`spacy-cleaner` ставится отдельно, потому что требует старый spaCy, который не собирается на Python 3.14 (с новым работает).

При первом запуске модель скачивается с Hugging Face: USER-bge-m3 весит около 1.4 ГБ, rubert-tiny2 — около 120 МБ.

Предупреждения `Token indices sequence length is longer than ... (653 > 512)` и `UNEXPECTED` при загрузке rubert-tiny2 безопасны: первое значит, что длинный текст будет обрезан, второе — что у модели есть неиспользуемые веса.
