# Альфа-Бизнес: персональный бизнес-обзор

Сервис сопоставляет новости и аналитику банка с деятельностью компании и ролью пользователя.
Интерфейс встроен в демонстрационную оболочку Альфа-Бизнеса: сводка, карточки с основаниями,
история версий и уточнения к конкретному выводу — без отдельного общего чата.

```text
Документы + анкета + банковские CSV → company-user-profiler → версия контекста
Новости → parser → PostgreSQL/pgvector → retrieval-ranking → insight-agent → обзор
                                     ↗                    ↖
                  embedding-service           tool-gateway → поиск/источники
Банковские PDF → bank-materials-source → OCR/RAG ──────────↗
```

**Запуск:** [infrastructure/README.md](infrastructure/README.md). Backend и frontend — http://localhost:8092/.
Демо-пользователь создаётся автоматически. Веса embedding/reranker скачиваются при первом полном запуске;
для генерации требуется разрешённый LLM endpoint и ключ в `infrastructure/.env`.

Новости отчёта ограничены интервалом `[начало, конец)` длиной 7 суток; недельная граница — понедельник
08:00 МСК. Поздние данные дают новую версию того же периода. Если анализ не завершён к сроку,
система публикует честное уведомление о неполноте, а не выдуманную аналитику.
Агент может искать более старые материалы как контекст. Мнения банка отделены от условных выводов AI.

Каждая папка сервиса содержит свой код и lock-файл; `service-common` переиспользуется агентами,
а `infrastructure` содержит общую конфигурацию и интеграционные тесты. Swagger backend: `/admin/docs`.
Проверки из `infrastructure`: `uv sync && uv run pytest`; PostgreSQL — через `TEST_DATABASE_URL`,
Chromium — через `RUN_BROWSER_TESTS=1`. Для браузерных тестов установите `uv run playwright install --with-deps chromium`.
Тесты с подставленными ответами моделей проверяют контракты, но не доказывают качество настоящей LLM.

Репозиторий содержит материалы задания: используйте **приватный** репозиторий с доступом команды и жюри.
