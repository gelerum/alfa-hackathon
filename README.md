# Альфа-Бизнес: персональный бизнес-обзор

Сервис собирает новости и аналитику банка, сопоставляет их с деятельностью компании
и задачами пользователя. В обзоре видны события, возможное влияние на бизнес и источники.
Основной сценарий расположен в оболочке Альфа-Бизнеса: выбор компании, персональный
обзор, источники и уточняющий вопрос к конкретному выводу.

**[Тестовый стенд: 5 компаний](https://backer-overplant-gills.ngrok-free.dev/)** ·
**[Раздел разработчика /dev](https://backer-overplant-gills.ngrok-free.dev/dev)**.
Демо-вход автоматический. Пароли и ключи в репозитории не хранятся.

## Запуск

Нужны Linux/WSL, Python 3, Docker с Compose v2.20+ и интернет.
Для запуска с внешней LLM ориентир — 16 ГБ RAM. Локальная генеративная Qwen требует
от 32 ГБ RAM; для всего стека рекомендуется 64 ГБ и не менее 35 ГБ свободного места.
На CPU анализ может занимать несколько минут; скорость зависит от процессора.

**С внешней LLM — две команды из корня репозитория.** Сначала подготовьте настройки:

```bash
./infrastructure/run-docker.sh --check
```

Откройте созданный `infrastructure/.env` в редакторе и укажите `OPENAI_BASE_URL`,
`OPENAI_API_KEY`, `OPENAI_MODEL` разрешённой модели. По умолчанию — `qwen3.6-35b-a3b`.
Затем запустите приложение:

```bash
./infrastructure/run-docker.sh --without-qwen
```

**С локальной генеративной Qwen — одна команда:**

```bash
./infrastructure/run-docker.sh --with-qwen
```

Откройте **http://localhost:8092/**. Демо-вход автоматический.
Скрипт сам создаёт `.env` и внутренние секреты, при первом запуске инициализирует БД.

Два режима одного приложения:

| Режим | Команда | Что работает в контейнерах |
| --- | --- | --- |
| С локальной LLM | `./infrastructure/run-docker.sh --with-qwen` | Все сервисы и генеративная Qwen3.6-35B-A3B через llama.cpp на CPU |
| С внешней LLM | `./infrastructure/run-docker.sh --without-qwen` | Все сервисы; генерация через настроенные `OPENAI_*` |

Qwen3-Embedding-0.6B и Qwen3-Reranker-0.6B работают в Compose **в обоих режимах**.
При первом `--with-qwen` скачивается около 22 ГБ весов GGUF; они сохраняются в volume.
Локальный endpoint и ключ подключаются автоматически, внешние настройки `.env` сохраняются.
`--without-qwen` останавливает только локальную генеративную Qwen, не удаляя её веса.
Внешний `OPENAI_BASE_URL` должен быть доступен из контейнеров: `localhost` внутри контейнера — сам контейнер.
`--ui` запускает только интерфейс и БД; `--check` проверяет конфигурацию без запуска.
Для Podman замените `run-docker.sh` на `run-podman.sh`.

## Как проверить

1. Выберите компанию. Локальная сборка содержит пять учебных компаний на синтетических данных;
   набор можно изменить через `DEMO_COMPANIES`.
2. Откройте «Мой фокус и документы», проверьте роль, направления ответственности и цели.
   При желании загрузите PDF, DOCX, XLSX или изображение и сохраните фокус.
3. Создайте бизнес-обзор и дождитесь обработки. Откройте карточку: проверьте событие,
   основания, ссылки и разделение фактов, позиции банка и выводов AI.
4. Нажмите «Уточнить», задайте вопрос к карточке и дождитесь ответа.
5. Смените компанию или цели и создайте новый обзор: сравните результат и историю версий.
   Состояние очередей и сервисов доступно на **http://localhost:8092/dev**.

Если LLM не настроена, полноценная аналитика недоступна: интерфейс не подменяет её готовыми ответами.
Результаты не являются инвестиционной рекомендацией. По Q&A организаторов выручка
в исходных данных указана за 2025 год в рублях; `1000` — техническая заглушка, а не выручка.
Другие границы интерпретации данных и план оценки качества описаны в [архитектуре](ARCHITECTURE.md).

## Как устроено

`Новости → parser → PostgreSQL/pgvector → retrieval-ranking → insight-agent → обзор`.
Профиль компании и цели пользователя подготавливает `company-user-profiler`;
`tool-gateway` даёт агентам доступ к источникам, документам и поиску.
`backend` обслуживает интерфейс и очередь заданий, `embedding-service` строит векторы,
`bank-materials-source` имитирует публикацию предоставленной аналитики банка.

Подробнее: [описание системы](ARCHITECTURE.md), [редактируемая схема draw.io](architecture.drawio),
[изображение схемы](architecture.png),
[сторонние компоненты, модели и данные](THIRD_PARTY_NOTICES.md).
Источники и версии контекста сохраняются; обзор охватывает семь суток,
а поздние материалы формируют новую версию. Факты, позиция банка и условные выводы AI разделены.

## Настройки и обслуживание

Все переменные с примерами — [infrastructure/.env.example](infrastructure/.env.example).
Основные: `OPENAI_*` — внешняя генерация, `QWEN_*` — локальная LLM,
`BACKEND_BIND_HOST` / `BACKEND_PORT` — адрес интерфейса, `DEMO_COMPANIES` — набор компаний.
По умолчанию наружу опубликован только backend на `127.0.0.1:8092`.
`INTERNAL_TOKEN`, `ADMIN_TOKEN`, `SEARXNG_SECRET` создаются автоматически.
API: **http://localhost:8092/admin/docs**.

```bash
cd infrastructure && docker compose logs -f backend-worker profiler-worker insight-worker
docker compose --profile local-llm down
```

Остановка без `-v` сохраняет БД, документы и модели.

При обновлении существующего стенда сначала разверните код этого выпуска и пересоберите
контейнеры выбранной командой запуска. Затем заново сохраните «Мой фокус» для каждой
проверяемой компании и создайте новый обзор: так появится профиль с уточнениями Q&A.
Исторические профили, источники и обзоры не переписываются. Пересохранение фокуса
на старой версии сервиса эти изменения не применяет.

Сведения о проверках — [infrastructure/README.md](infrastructure/README.md).
Версию сдаваемого решения фиксируйте командой `git rev-parse HEAD` после финального коммита.
Для приватного репозитория предоставьте доступ жюри `alfa-hack-2026`.
Данные задания предназначены для команды и жюри; не публикуйте их за пределами разрешённого доступа.
