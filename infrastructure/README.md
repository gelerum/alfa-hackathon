# Запуск

Нужны Python 3 на хосте, Docker Compose v2.20+ или Podman с Compose provider,
интернет и около 16 ГБ RAM. Запускайте команды на хосте, не внутри dev-контейнера.

**Из существующей локальной копии** — находясь в корне репозитория:

```bash
cd infrastructure && ./run.sh
```

**Из Git** — задайте `REPO_URL` адресом единого приватного репозитория:

```bash
git clone "$REPO_URL" alpha && cd alpha/infrastructure && ./run.sh
```

Откройте **http://localhost:8092/**. Демо-вход автоматический.
Скрипт создаст `.env` и случайные секреты; существующие настройки сохранит.
Для аналитики заполните в `.env` `OPENAI_BASE_URL`, `OPENAI_API_KEY`, `OPENAI_MODEL`.
При первой загрузке моделей запуск может занять несколько минут.

Только посмотреть интерфейс с БД: добавьте `--ui` к `./run.sh`.
Выбор движка при необходимости: `CONTAINER_ENGINE=podman ./run.sh`.
Демо — общий тестовый аккаунт; не выставляйте его с реальными данными в интернет.
Остановка без потери данных: `podman compose down` (или `docker compose down`), **без `-v`**.
