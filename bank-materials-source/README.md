# Моделируемый источник аналитики Альфа-Банка

Независимый HTTP-сервис с SQLite-каталогом и версионированными PDF.
Начальные файлы используются только для seed; потребитель опрашивает cursor API.
`POST /materials` позволяет показать поступление нового материала без перезапуска.

Реализация: `bank_source_service/api.py`. Локально из этой папки:
`uv sync`, затем `uv run uvicorn bank_source_service.api:app --port 8091`.
Настройки передаются через окружение; общий код подключается из `../service-common`.
