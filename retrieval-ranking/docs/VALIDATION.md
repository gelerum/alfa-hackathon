# Проверка минимального модуля

Дата: 25.10.2026. Основная конфигурация — PostgreSQL vector + FTS,
Qwen3-Reranker-0.6B CPU float32, batch=2, 2048 токенов на пару,
512 на контекст, 4 потока. .env.example выбирает инструкцию V0-i2.
Обучение не запускалось.

## Состав проверки

В минимальном наборе 106 тестов:

- 84 обычных проверки API, SQL-адаптеров, сервиса, текста и адаптера модели;
- 20 PostgreSQL/HTTP-проверок без загрузки модели;
- 2 opt-in проверки с настоящим закреплённым Qwen, включая SQL → HTTP → запись результата.

Полный набор из 106 проверок пройден с существующим локальным кэшем модели
и собственной изолированной PostgreSQL/pgvector БД.
В отдельной копии публикуемого набора без исследований, датасетов,
.env, .venv и модельного кэша пройдено 104 проверки, 2 model-проверки исключены.
Для этой проверки использовано уже установленное окружение зависимостей;
новая установка пакетов не выполнялась. Ruff и uv lock прошли.
Все ссылки ведут на файлы, входящие в этот минимальный набор.

Фикстуры содержат синтетические компанию, пользователя, новости и векторы.
fixtures/schema.sql — тестовая копия общей схемы с provenance,
а не миграция для командной БД.

Команды воспроизведения приведены в [README](../README.md).
Настоящие веса закреплены на revision
`e61197ed45024b0ed8a2d74b80b4d909f1255473`.

## Выбор инструкции

Ранее проведено сравнение V0 и V0-i2 на 147 validation-парах
четырёх компаний: одинаковые видимые контексты, тексты, веса и лимиты;
менялась только инструкция. 144 пары имеют черновую LLM-метку,
3 неизвестные оценки исключены из метрик. Test для оценки не использовался.

| Метрика | V0 | V0-i2 |
| --- | ---: | ---: |
| Macro 2>1 | 0,7359 | 0,8237 |
| Macro 2>0 | 0,9503 | 0,9743 |
| Macro 1>0 | 0,8001 | 0,7996 |
| nDCG@10 | 0,8174 | 0,8500 |
| P@5, оценки 1 и 2 | 0,90 | 1,00 |
| Сильных в top-5 | 6/11 | 7/11 |

2>1 и 2>0 — среднее по трём компаниям с обоими классами.
Всего сильных пар 14, но в top-5 отдельных компаний максимально помещаются 11.
P@5 учитывает фоновые полезные новости с оценкой 1 и не означает идеальную выдачу.
У software и metal nDCG снизился; превосходства на всех срезах нет.

i2 выбрана по улучшению 2>1, 2>0 и strong top-5.
Метки не являются экспертным gold-набором.
Исследовательские тексты, разметка, скрипты и промежуточные результаты
сохранены локально, но не входят в минимальную поставку.
Для запуска сервиса они не нужны: инструкция i2 целиком записана в .env.example.
Воспроизведение этого исследования требует отдельно подготовленных данных.

## CPU и сквозные сценарии

На Intel Core Ultra 9 275HX, WSL с 12 доступными CPU,
проверена собственная БД с 6410 реальными спарсенными публикациями.
SQL отобрал фиксированные 37 кандидатов; HTTP/TestClient → Qwen → БД
завершился с 200 OK и сохранением всех 37 оценок.

| Профиль | Время после startup | Усечено новостей |
| --- | ---: | ---: |
| 2048 токенов / 4 потока | 177,10 с | 3/37 |
| 1024 токена / 12 потоков | 66,79 с | 18/37 |

Контекст не усечён. Один повтор — не SLA и не p95.
Короткий профиль одновременно меняет длину и число потоков;
на validation 2>1 немного снизился, 1>0 ухудшился, strong top-5 остался 7/11.
Он не включён по умолчанию.

Отдельный внешний TCP/HTTP smoke через uvicorn:
синтетические 5 кандидатов, 200 OK, 3 новости в ответе и 5 оценок в БД.
Startup с кэшированной моделью — 4,53 с, запрос — 4,23 с.
Это короткие данные и не оценка времени длинного новостного пула.

Проверены CPU-импорт Docker-образа, обычный UID, запись в кэш
и соединение контейнера с тестовой БД.
Полный контейнерный запуск модели тогда не подтверждён:
Docker Desktop отклонил монтирование кеша из WSL из-за недоступного ubuntu.sock.
Работа Qwen в WSL проверена отдельно.

## Ограничения

Техническая проверка модуля не подтверждает интеграцию всей командной сборки.
Для неё нужен /rank на данных её upstream-модулей.

Улучшение инструкции не устраняет все ошибки бизнес-смысла:
для компании с металлоконструкциями в реальном примере наверх попала
новость про аграрную торговлю с Китаем. Связь только по стране недостаточна.
Для этого полного пула нет полной экспертной разметки.

Полный исследовательский комплект раньше содержал 455 проверок без
model-маркера. Это историческое число; к минимальному модулю относятся 106
проверок, описанные выше.
